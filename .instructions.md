# Instruções do Projeto AutoZap (AutoAtende)

## Antes de Começar
1. Ler `PROJETO_AUTOMACAO_WA.md` — fonte única de verdade
2. Seguir a ordem das fases: 0 → 1 → 3 → 4 → 2 → 5 → 6 → 7
3. Pedir aprovação do usuário ao concluir cada fase antes de avançar

## Padrão de Commits
- `feat: descrição` - nova funcionalidade
- `fix: descrição` - correção de bug
- `docs: descrição` - documentação
- `chore: descrição` - tarefas auxiliares
- `refactor: descrição` - refatoração

## Stack (não alterar sem aprovação)
- Infra: Docker · PostgreSQL 15 · Redis 7 · Nginx Proxy Manager
- Serviços: Evolution API · Typebot · n8n · Chatwoot
- Frontend: Next.js 14 (App Router) · Tailwind · shadcn/ui · Framer Motion
- IA: GPT-4o-mini via API direta (sem LangChain)

## ⚠️ OBRIGATÓRIO — AO CRIAR ESTE PROJETO NO PORTFOLIO
1. Criar `Portfolio/src/pages/projects/AutoZap.tsx` (scaffold de arquivo existente)
2. Registrar rota em `Portfolio/src/App.tsx`:
   ```tsx
   import AutoZapPage from './pages/projects/AutoZap';
   <Route path="/projetos/autozap" element={<AutoZapPage />} />
   ```
3. Adicionar card em `Portfolio/src/SimpleApp.tsx` → array `projectsRaw`:
   ```tsx
   { number: '04', noImage: true, name: 'AutoAtende', description: 'Automação de atendimento WhatsApp com IA para MPEs da Baixada Santista',
     stack: ['Docker', 'n8n', 'Typebot', 'Next.js', 'OpenAI'], status: 'Em dev', stage: 'dev',
     progress: 5, lastUpdate: '2026-05-23', projectPath: '/projetos/autozap' }
   ```
4. Adicionar entrada em `BuildStatus` (mesmo arquivo):
   ```tsx
   { name: 'AutoAtende', stage: 'dev', progress: 5, lastUpdate: '2026-05-23', desc: 'Automação WA com IA' }
   ```

## ⚠️ IMPORTANTE — ATUALIZAÇÃO DE PORTFÓLIO (commits futuros)
1. Editar `.project.md` → seção "Última Atualização" e % de Progresso
2. Atualizar `progress` e `lastUpdate` no card do `SimpleApp.tsx` e `BuildStatus`
3. Rodar `python AgenteMestre/sincronizar_portfolio.py`

## Regras de Segurança
- Nunca commitar `.env` — usar `.env.example` com placeholders
- Porta 81 (NPM admin) deve ser bloqueada após configuração
- n8n e Evolution API com autenticação obrigatória
